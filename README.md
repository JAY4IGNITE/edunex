# CampusPulse AI

Smart Campus Analytics: Predict, Understand & Improve Student Success

This repository is initialized for the KPMG India Challenge 04 / HacXLerate workflow.

## Current implementation status

Only Phase 0 and Phase 1 are authorized at this stage.

- Phase 0: repository inspection and architecture foundation
- Phase 1: PRD, data contracts, dataset registry, provenance, validation and database foundation

The implementation must STOP after these phases until explicitly approved to continue.

## Core product flow

Data → Student 360 → Success Score → Risk → Explanation → Segmentation → Insights

## Important data policy

Do not claim that a public dataset contains fields that it does not contain.
Do not merge unrelated public datasets by student ID.
Any demonstration institutional data must be explicitly labelled as demonstration/simulated data.
Unknown source mappings or licenses must remain `UNKNOWN — REQUIRES VERIFICATION`.
