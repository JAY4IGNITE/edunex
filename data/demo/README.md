# CampusPulse Demonstration Data

**DEMONSTRATION — NOT REAL INSTITUTIONAL DATA**

This directory contains synthetically generated data that realistically simulates the seven required KPMG domains:
- Academic
- Attendance
- LMS
- Engagement
- Placement
- Skills
- Feedback

The data uses correlated profiles to ensure analytical validity.

## Reproduction
Run the following script to regenerate the dataset:
`python backend/scripts/generate_demo.py`
